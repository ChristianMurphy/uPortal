# Research notes

Background research behind the uPortal 6.0 modernization plan, collected in October 2026.

* [REPORT.md](REPORT.md) is the synthesized report: the migration path, gotchas, risk register, phased plan, workstreams and upstreaming strategy.
* The other files are the per-topic research notes the report cites, and two local inventories of the uPortal and uPortal-start code.

Citations point at primary sources wherever possible. Facts that only came from search snippets say so in the text.

These notes describe uPortal and uPortal-start `master` as they were on 2026-10-10, before the
prototype work began. Facts such as tool and library versions have changed on the integration
branch since. Where a note and `../LOG.md` disagree, the log is current.
